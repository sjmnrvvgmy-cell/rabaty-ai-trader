# RABATY AI TRADER

Start with `README_MOBILE.md` for the iPhone + free-hosting setup.

The mobile/free edition uses GitHub Actions for best-effort scheduled Telegram BUY/SELL alerts and Streamlit Community Cloud for the web dashboard. The standalone `bot.py` is a polling bot for an always-on host; it is not used by the free scheduled workflow.

Read the limitations in `README_MOBILE.md` before relying on alerts. This is an unvalidated signal prototype, not financial advice.
